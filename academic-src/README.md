# Rakibul Amin — Academic portfolio

Built with the actual Academic Pages Jekyll template. See TEMPLATE.md and LICENSE for provenance and attribution.

## Build

Install Ruby, Bundler, and the gems in Gemfile, then run:

    npm install
    bundle install
    npm run build

The generated static site is deployed through the existing Sites project. Content lives in _pages, _research, _publications, and _portfolio. Navigation is in _data/navigation.yml.
